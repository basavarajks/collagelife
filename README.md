# SDMS repository

Phase 1 added the public React college homepage, login UI, Flask application factory, SQLAlchemy models, migrations, and local admin seed foundation. Phase 2 adds real database-backed authentication, server-side token revocation, normalized roles and permissions, audit logs, `/me`, logout, password change, centralized authorization, and frontend authentication rehydration.

Use `backend-flask/README.md` for the exact Windows 11/XAMPP setup and migration commands. The existing Flutter and Django applications remain unchanged.

Phase 2 remains limited to authentication and access-control foundations. Role dashboards and SDMS modules are deferred to later phases.
